# Apple Wallet Pass Assets

This directory contains the image assets used in Apple Wallet passes.

## Required Files

### Icons (square, no transparency)
- `icon.png` - 29×29 px
- `icon@2x.png` - 58×58 px
- `icon@3x.png` - 87×87 px

### Logos (rectangular, can have transparency)
- `logo.png` - 160×50 px (recommended)
- `logo@2x.png` - 320×100 px
- `logo@3x.png` - 480×150 px

## Creating Assets

You can create these from your existing logo using image editing software or ImageMagick.

See `WALLET_SETUP_GUIDE.md` in the project root for detailed instructions.

## Design Guidelines

- Icons should be simple and recognizable at small sizes
- Use your brand colors
- Logos should be clear and legible
- All images should be PNG format
- Use @2x and @3x versions for Retina displays
